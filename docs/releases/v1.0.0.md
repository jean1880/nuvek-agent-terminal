Agent Terminal 1.0.0 is the first public release: a native Linux desktop app for working with AI coding agents. Claude Code, Antigravity (`agy`) and Codex run as chat threads, with approvals, plans, diffs and undo built in, and a terminal one keystroke away. It is written in Rust with GTK4 and libadwaita and ships as a single binary.

Agent Terminal is an independent project, not affiliated with Anthropic, Google or OpenAI. It drives their command-line tools, which you install and sign in to yourself.

## Highlights

- **Switch agents in the middle of a conversation.** A thread is not tied to one agent. Move it between Claude, Antigravity and Codex from the model picker or `/model`; the new agent is handed the conversation so far, and the thread keeps one history across all of them.
- **One window for three agents.** Threads from all three agents live in one searchable sidebar grouped by folder, including Claude and agy sessions you already ran in those CLIs.
- **You stay in control.** One approval card for every agent (Allow, Allow for session, Always allow, Deny, Stop turn), a plan panel, and questions the agent asks as cards with answers to pick.
- **Approval rules you own.** Session and always rules live in Agent Terminal, are kept exactly as you write them, and answer matching requests from all three agents.
- **Multi-agent environment review.** One confirmed action opens a review in the exact work folder, with a scorecard, skill and MCP recommendations and an ordered improvement guide.
- **Delegation.** An agent can start sub-agents on any of the three, within limits its parent declares; sub-agent approvals and questions surface in the parent thread.
- **Git safety net.** Each turn is checkpointed into hidden refs. The diff panel shows what changed, undo puts it back, and a worktree gives an agent its own checkout. Your branch, index and stash are never touched.
- **Your desktop, your colours.** The bundled Agent Terminal theme, six classics, or **Use System Theme** to follow your desktop's GTK theme, light or dark.

## Safe by design

- Secrets are masked before anything is stored, injected into a hand-off or shown in a diff.
- Hand-off briefs are written `0600` in a `0700` folder outside any project.
- Antigravity runs with its permissions bypass only once its approval hook is proven to be in place.
- The app exposes no ports. Its one outbound request is an update check, which Settings can turn off.

## Install

Download the package for your distribution and `SHA256SUMS` from this release, verify the checksum (and, optionally, the build provenance with `gh attestation verify <file> --repo jean1880/nuvek-agent-terminal`), then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_1.0.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-1.0.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-1.0.0-1-x86_64.pkg.tar.zst` |

It needs GTK 4.10+, libadwaita 1.5+, VTE 0.72+ and GtkSourceView 5, and at least one agent CLI (`claude`, `agy` or `codex`). To remove it, run `agent-terminal --uninstall`.

## Known limitations

- A hook file created, or a plugin symlink retargeted, after agy's hook proof and before agy reads its hooks is not seen by the proof. A canary bounds it to one unasked step.
- Codex as a sub-agent starts its own workers outside Agent Terminal's limits, agy children need the managed bridge, and closing the app ends every child.
- The redactor works by pattern: names with no sensitive part, values under 8 characters and multi-line values are not caught.
