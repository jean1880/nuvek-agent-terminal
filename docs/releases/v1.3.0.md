Agent Terminal 1.3.0 prepares the thread store for the features to come and fixes two readings that were wrong: Antigravity's context window and Claude's cost per turn.

## Changed

- **The thread store moves to schema 11.** It adds the tables later releases fill: pins and tags for threads, message search, scheduled prompts, a spending history and saved diff-review comments. They stay empty in this release. The upgrade runs once at start-up, after a verified backup of the store, and reads none of your threads' events, so it takes the same short time on any store.
- Keyboard shortcuts are now kept in one table, and a test fails when two actions share a key.

## Fixed

- **Antigravity's context window is no longer guessed.** Antigravity does not say how large a model's window is, and the header claimed 1,048,576 tokens for every model, so a nearly empty gauge looked healthy when the size was unknown. The header now shows the tokens used with no percentage or bar, and the tooltip says the size was not reported.
- **Claude's cost is recorded per turn.** Claude reports a running total for the life of its process, and each turn stored that total as its own cost. A turn now records only its own cost. The first turn after a resumed session records none, because it cannot be told apart from the session's earlier spending. Costs are not shown yet; this fixes the data before a later release shows it.

## Upgrade and install

Existing settings and threads are kept. Before the store moves to schema 11, Agent Terminal copies it into a private `backups` folder beside it and verifies the copy.

Download the package for your distribution and `SHA256SUMS` from this release, verify the checksum (and, optionally, the build provenance with `gh attestation verify <file> --repo jean1880/nuvek-agent-terminal`), then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_1.3.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-1.3.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-1.3.0-1-x86_64.pkg.tar.zst` |

## Known limitations

- **Going back to an older version.** A build older than 1.3.0 cannot open a store that 1.3.0 has upgraded. It starts with an empty, temporary thread list and says nothing about why. Your threads are untouched on disk and return when you install 1.3.0 or newer again.
- The 1.2.0 limitations still apply.
